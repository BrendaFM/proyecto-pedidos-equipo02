# Registro de marcas

Este módulo permite registrar marcas con su nombre, descripción y estado.

Para utilizarlo, abre el archivo src/inicio.html en el navegador,
completa los campos y presiona Guardar marca.

El nombre es obligatorio y no se permiten marcas repetidas,
aunque se escriban con diferentes mayúsculas o minúsculas.

El botón Limpiar restablece los campos del formulario.

Las marcas se guardan en el navegador y vuelven a aparecer
al recargar la página. Los registros no se comparten entre equipos.g
